01Component diagram

Architecture type: event-driven microservices with an orchestrated agent harness. Patterns used: API gateway (G1) · database-per-service (D1, MongoDB) · event-driven integration over a broker (X3) · orchestrator state machine (H1) · competing-consumer workers (H2–H4) · shared versioned libraries (P1–P7) · policy sidecar (X2) · routes → services → repository inside every service.
