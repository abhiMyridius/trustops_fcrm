## Rules that apply everywhere

- Contracts first: every shape is imported from `fcrm_contracts`; no lane defines a local copy. A contract change updates fixtures and `docs/architecture/openapi` / `events` exports in the same commit (`make contracts` must be clean).
- Scores come only from `fcrm_scoring`; agents never emit a score, band or rating decision. Policy text is quoted verbatim with a `source_ref`, never generated.
- Model ids live only in `ai/models/tiers.yaml`. Prompts live only under `ai/prompts` and need a version bump on change; the lock tests enforce both.
- `src/packages/seed/.../seed.json` is generated by `gen_seed.py`; never edit it by hand. `src/web/src/api/generated/**` is generated by `make api-gen`.
- Every state change writes an audit record through S4 and goes through the outbox in the same Mongo transaction. Human decisions carry a reason.
- The PO role never receives score, band, rating or harness data in any response, stream or page.
- Never read `.env*` or anything under `~/MacWorkspace/EVOQ_Applications/AEO/secrets`. Cloned AEO code carries an `UPSTREAM.md`; fix bugs there and list them.
- Every FastAPI service's module-level `app` (what `uvicorn <pkg>.main:app` serves) must be mounted under its `APP_ROOT_PATH` via `fcrm_common.asgi.mount_at_root_path` (D-13): nginx's `proxy_pass` forwards the full request path unmodified, so a bare, unmounted app 404s on every real request and its own healthcheck. `create_app()`/equivalent should keep returning the bare app (what unit tests exercise directly); only the module-level `app` wraps it. `fcrm_scoring/main.py` is the reference implementation.
- Commit small and often: `type(scope): summary [D-xx, ADR-nn]` with `Stage:` and `Gate:` trailers. `make check` must be green before a commit (the Stop hook enforces it); `make gate` before reporting a task done. Governance tables under `docs/governance` are append-only.
- Coding standards are `ai/guidance/coding-standards.md` (ADR-21) and are enforced by ruff, mypy and the hooks: Python 3.13, uv workspace at `src/`, Pydantic 2 with `extra="forbid"` DTOs, type hints on every signature, docstrings on public symbols, `logging` never `print`, specific exceptions only. Tests never sit beside source: `tests/unit/<src path>` and `tests/integration/<src path>` with fixtures only in `tests/conftest.py`; config never inside `src/`. TypeScript strict, no business arithmetic in the client.

## Commands (available once the scaffold lands)

```bash
make bootstrap     # uv sync, pre-commit install, pull images
make up / down     # full stack via docker-compose (22 containers)
make seed-verify   # seed loaded and the 80-case recompute matches
make demo          # drive FCRM-2026-0151 end to end and assert the goldens (9.8 → 10.4, 2–1, 67 records)
make check         # commit gate: ruff, mypy, unit tests, tsc, vitest, governance checks  (< 90 s)
make gate          # push gate: everything in check for all packages + contract tests + eval gate  (< 10 min)
make e2e           # 21 Playwright scenes + black-box suite BB-01…BB-14 against the composed stack
make evals         # per-agent eval run; writes evals/results/<date>/
uv run --package fcrm-scoring pytest tests/unit/services/scoring -k golden   # one unit, one test selection
```

`pytest.ini`'s `testpaths = tests` means an unscoped `pytest` call collects every unit's tests in one process. `--package <name>` only installs *that* unit's dependencies, so a bare `pytest` (no path) under `--package` fails collection on another unit's imports — pass the specific `tests/unit/<...>/<unit>` (or `tests/integration/...`) path alongside `--package` for a single unit's tests. For the whole suite at once, `make test-unit` (or `uv run --project src --all-packages pytest -m "not integration and not e2e"`) installs every workspace package's dependencies together and collects cleanly in one process — this is the real fix, not a workaround, and is what `make check`/`make gate` use.
