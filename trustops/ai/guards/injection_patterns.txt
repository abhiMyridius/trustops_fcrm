# ai/guards/injection_patterns.txt  (Guard 1, version 1)
#
# Format: one Python `re` pattern per line, matched case-insensitively against
# canonical document text, owner free text and every pack section. An
# optional weight prefix "[w=0.N] " sets the line's weight (default 0.5).
# The scan score is min(1.0, sum of weights of distinct lines that hit);
# >= thresholds.injection_score_block blocks and quarantines, >= amber gets
# a cheap-tier second opinion. Lines starting with "#" and blank lines are
# ignored. Red-team rows live in evals/redteam/injection-50.jsonl; every new
# pattern needs a row there that it catches and a benign row it must not.

# --- instruction override ---------------------------------------------------
[w=0.9] \b(ignore|disregard|forget|override)\b.{0,30}\b(all |any |the )?(previous|prior|above|earlier|preceding|system)\b.{0,20}\b(instructions?|prompts?|rules?|directions?|context)\b
[w=0.8] \bdo not (follow|obey|apply)\b.{0,30}\b(instructions?|rules?|system prompt)\b
[w=0.8] \b(new|updated|revised|real) (system )?instructions?\s*[:\-]
[w=0.6] \bfrom now on\b.{0,40}\b(you (will|must|should)|always|never)\b

# --- role reassignment --------------------------------------------------------
[w=0.8] \byou are (now|no longer)\b
[w=0.7] \b(act|behave|respond|pretend) (as|like) (if you (are|were) )?(an?|the) (unrestricted|different|new|developer|admin|jailbroken)\b
[w=0.7] \b(developer|debug|god|jailbreak|dan) mode\b

# --- fake conversation / chat-template markers --------------------------------

[w=0.7] \[/?(INST|SYS)\]|<<\s*/?SYS\s*>>
[w=0.6] </?(system|instructions?|prompt)>
