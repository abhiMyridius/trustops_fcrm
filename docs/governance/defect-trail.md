# Defect trail

Append-only. Every defect found during development, its severity, where it was found, and its disposition. Distinct from `failure-log.md` (which is about the *build process* stalling or erring) — this is about defects *in the product* the build produces.

Severity: **P1** blocks a milestone or violates a product rule · **P2** should fix before freeze · **P3** tracked, not blocking.
